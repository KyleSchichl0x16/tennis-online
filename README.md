# Tennis Game – online two-player

A browser port of the Flash "Tennis Game" by [GAMEDESIGN](http://www.gamedesign.jp/), with the
computer opponent replaced by a second human player. The game design, art and sounds are theirs.

Play: create a match, send the link to a friend, and start once they have joined. Arrow keys
to move, Space to hit; the direction held at the moment of contact aims the shot.
